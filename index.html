Nine tightly integrated study modules covering Product Sense, SQL, Python, Data Modeling, Pipeline Reliability, AI/ML, Dashboards, Behavioral, and Spark ETL — designed around how Meta's actual onsite rounds are structured.

📅 4-Week Study Plan 📋 Recall Sheet

How to Use This Guide

The actual onsite throws Product Sense, Data Modeling, SQL, and Python at you inside one 45-minute conversation — not as four separate topics. Treat Modules 1–4 as a single integrated skill. 

Product framing  →  Event payload  →  Star schema  →  SQL query  →  Python transform
   (2–3 min)          (5 min)          (8–10 min)      (15 min)          (10 min)

Interview loop
  ├─ Recruiter Screen  (30 min) — Project overview
  ├─ Technical Screen  (60 min) — 5 SQL + 5 Python speed round
  └─ Onsite  (4–5 rounds)
       ├─ 3× Blended: Product Sense → Data Model → SQL → Python
       └─ 1× Behavioral & Ownership (STAR)
